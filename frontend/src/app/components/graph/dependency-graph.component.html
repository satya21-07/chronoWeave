How to Draw Dependencies

You can visually map dependencies between tasks directly on the graph:

Link Tasks: Hover over a task. A blue connection dot will appear at its bottom. Click and drag from this dot, then drop it anywhere on the top half of the dependent task.
Unblock flow: Complete a task to automatically unblock all downstream tasks.
Cycles blocked: Circular links (e.g., A → B → A) are automatically prevented.
Color Legend:
Red Link: Critical Path
Gray Link: Normal Link
Green Node: Completed
Yellow Node: In Progress
Red Node: Blocked
Gray Node: Not Started
